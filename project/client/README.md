# Client (Фронтенд проекта)

Клиентская часть сервиса на **React + TypeScript + Vite**.

## 🎯 Основные интерфейсы
1. **Конструктор схем (`/constructor`)**: визуальный холст для создания этажей, полигонов зон и расстановки столов (drag-and-drop, вращение, ресайз, сетка, публикация ревизий).
2. **Гостевое бронирование (`/booking`)**: выбор даты/времени/числа персон, интерактивная 2D-схема залов со свободной/занятой подсветкой столов, оформление брони.
3. **Личный кабинет гостя (`/profile`)**: список предстоящих и архивных бронирований, отмена бронирования.
4. **Панель менеджера (`/manager`)**: шахматка столов по времени, календарный журнал, ручное бронирование, фиксация no-show.

## 🛠 Технологии
- React 18 / 19
- TypeScript
- Vite
- Tailwind CSS
- Socket.IO Client
