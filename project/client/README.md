# Client (Фронтенд проекта)

Клиентская часть сервиса на **React 19 + TypeScript + Vite**.

## 🎯 Основные интерфейсы
1. **Схема зала (`Схема зала`)**: визуальный холст для создания этажей, полигонов зон и расстановки столов (drag-and-drop, вращение, сетка, публикация ревизий).
2. **Бронирование (`Бронирование`)**: выбор даты/времени/числа персон, интерактивная 2D-схема залов со свободной/занятой подсветкой столов, оформление брони с soft-lock.
3. **Журнал зала (`Журнал зала`)**: шахматка столов по времени, карточка брони, посадка гостей, no-show, ручное бронирование по телефону.

## 🛠 Технологии
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons

## 🎨 Дизайн-система

Интерфейс собран как редакционный ресторанный продукт: тёплая бумага, хвойный структурный цвет,
бордо для занятости и латунь только для акцентов.

| Токен | Значение | Роль |
|---|---|---|
| `paper` | `#F7F2E8` | фон страницы |
| `stone-50 / 100` | `#FBF8F1` / `#F4EEE3` | поверхности, панели |
| `stone-200 / 300` | `#E9DFCE` / `#D8CBB4` | линии, границы |
| `ink` / `stone-900` | `#17130F` / `#1E1913` | текст, первичные действия |
| `emerald-700/800` | `#274A3A` / `#1D3A2E` | свободные и подходящие столы |
| `rose-700` | `#5E2326` | занятые столы, no-show |
| `amber-600` | `#8A6836` | фокус, активный раздел, акцент |

Типографика: **Lora** для заголовков и номеров столов, **Golos Text** для интерфейса.
Радиусы 2–4 px, тени почти отсутствуют — иерархия строится линиями и отступами.

Схема зала — архитектурный чертёж: толстые стены, окна, двери с дугами открывания, кухня с плитой и мойкой,
санузлы, банкетки и стулья рисуются как мебель, а не как абстрактные прямоугольники. Доступность стола
показывается обводкой столешницы (зелёная — подходит, тёмная — свободен, бордовая со штриховкой — занят,
пунктир — не подходит), а не перекраской всей фигуры.

Правила, которые важно соблюдать при доработке:

- Никаких `hover:scale` / `hover:-translate` на элементах схемы и карточках: hover меняет только
  `stroke`, `stroke-width`, `background-color` или `border-color`. Это же правило убирает «тряску».
- Состояние стола кодируется не только цветом: у недоступных — пунктир, у занятых — диагональная штриховка.
- Все подписи не мельче 12 px; контраст текста к фону — не ниже 4.5:1.
- Один смысловой акцент на экран: заголовок, затем данные, затем действия.

## 🚀 Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # tsc + production build
npm run preview  # предпросмотр production-сборки
```
