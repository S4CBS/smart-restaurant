# Умный ресторан (Smart Restaurant)

Веб-приложение для ресторанов: интерактивный 2D-конструктор схем залов и сервис онлайн-бронирования столов.

## 📌 О проекте

Проект решает задачу быстрой оцифровки планировок залов заведения и удобного выбора конкретного стола гостями при бронировании:
- **2D-конструктор залов**: визуальный редактор для проектирования этажей, функциональных зон (полигонов) и расстановки столов (круглые, квадратные, прямоугольные) с вращением, привязкой к сетке и версионированием ревизий планировки.
- **Гостевой модуль бронирования**: интерактивная карта залов с дифференциацией доступности столов на выбранный слот времени, мгновенное бронирование и личный кабинет гостя.
- **Панель менеджера / администратора**: календарный журнал (шахматка), оперативный перенос/отмена броней, фиксация no-show, управление правами доступа.

## 🛠 Технологический стек

- **Frontend**: React, TypeScript, Vite, SVG-рендерер `<FloorPlanSVG>`, Socket.IO Client
- **Backend**: Node.js, Express / NestJS, TypeScript, Socket.IO
- **База данных**: PostgreSQL, Prisma ORM
- **Тестирование**: Vitest, Supertest

## 🚀 Быстрый старт (планируемый запуск)

```bash
# Клонирование репозитория
git clone https://github.com/S4CBS/smart-restaurant.git
cd smart-restaurant

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

## 📡 Ключевые модули и API

- `/api/v1/auth/*` — регистрация, авторизация (JWT).
- `/api/v1/layout/*` — получение схем этажей (публичный) и управление черновиками/ревизиями конструктора (`constructor`, `admin`).
- `/api/v1/booking/*` — расчет свободных слотов, проверка коллизий и оформление броней.
- **WebSocket (Socket.IO)**: комнаты `layout:edit` (блокировка одновременного редактирования) и `booking:updates` (live-обновление статуса столов).
